# air_quality_monitoring
本プロジェクトは、AWS上のパブリックデータであるOpenAQ（グローバル大気質データ）を活用し、健康リスクの高い地域を特定するダッシュボードを構築した成果物です。自動化処理は省き、データエンジニアリングのコアスキルであるデータモデリングとPower BIによる可視化に一点集中して開発を行います。

## 使用スキル・ツール
クラウド環境にAWS（S3、Athena）を利用し、データウェアハウスにSnowflake、BIツールとしてPower BIを採用したモダンデータスタック構成です。AWS Athenaのサーバーレスクエリを用いた効率的なデータ抽出 と、Snowflake上での高度なSQL処理（Window関数などによる指標作成）を駆使しています。

## 扱ったデータについて
AWSのオープンデータスポンサーシッププログラムでホストされている、OpenAQのデータセットを利用しました。データは s3://openaq-data-archive/ バケット内にgzip圧縮されたCSV形式（csv.gz）で保存されています。また、観測所ID（locationid）ごとに分割されたApache Hiveパーティション形式となっています。

## 手順
まずAWS Athenaで対象の観測所IDのデータを抽出し、自身のS3バケットにCSVとして保存。次にSnowflakeの外部ステージからデータをロードし、SQLのWindow関数を用いて移動平均や超過アラートフラグなどの分析用マートを作成しました。最後にPower BIと接続し、大気汚染の数値や危険度をバブルマップでインタラクティブな可視化を実現予定です。
